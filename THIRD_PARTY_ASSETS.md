PomoQuote itself is MIT licensed (see [LICENSE](LICENSE)). The assets with their own terms are listed here. Other bundled assets (sentences, mascot, sounds, wallpapers, weather icons, PomoQuote logo) are listed in the `CREDITS.md` file of their folder.

## Provider logos (`Assets/Providers/`)

PomoQuote shows the logo of the AI service whose quota it displays, next to the numbers, so the user can tell the providers apart (nominative use). **The names and marks of OpenAI, Anthropic and Google belong to their owners. PomoQuote is not affiliated with, endorsed by or sponsored by any of them.** A file licence (CC0, MIT) is not a trademark licence, so each vendor's own terms were checked; the result per provider is below. Nothing is fetched at run time: the files are packaged in the program. The logos are only scaled (never recoloured, cropped or combined with other marks); an error, stale data or a near-full quota is shown by a separate badge and by text, never by changing the logo.

### Normalisation

At load time each logo is cut to its visible pixels (the official files keep wide transparent margins, which made the mark small), then scaled once per size with high quality so the mark fills an about 20 px box at full brightness (white versions on the dark widget, black or full-colour versions in dialogs). This is done in memory; the files in `Assets/Providers/` are byte-identical to the vendors' files (a test checks the Codex one). No logo is ever recoloured to show an error.

### Decisions

- **Codex:** OpenAI publishes no separate Codex logo. The OpenAI Blossom identifies the OpenAI service (Codex) whose data is shown and is used unmodified, in the white and black versions OpenAI supplies, with the name "Codex" in the header, tooltip and accessible name. If OpenAI withdraws permission or the owner of this project prefers not to rely on it, delete `codex-on-dark.png` and `codex-on-light.png`: the widget then shows a neutral letter tile and the name.
- **Claude Code:** the owner asked for the real Claude mark. Candidates checked on 2026-11-24: (1) Anthropic's own press kit (anthropic.com/news "Download press kit", `https://assets.claude.com/ae59ca4ca194dac9c9dc3bc78c5829468cb0e8af.zip`: Claude Spark, Claude icon, Claude logo and Claude Code logo, no usage terms in the kit); (2) **lobe-icons** (MIT) `claudecode-color.svg` (the Claude Code mark) and `claude-color.svg` (the Claude mark); (3) **Simple Icons** (CC0 files, `claude.svg`, the Claude spark, commit `7a6199a2ac7d20b529f863b6aceb20d2c6529207` of 2024-11-29). Anthropic's [trademark guidelines](https://www.anthropic.com/legal/trademark-guidelines) say its marks may be used "only as specifically permitted by us and only in materials we approve beforehand" and forbid alterations, so the press kit was not used without approval. The **lobe-icons Claude Code mark was chosen**: it is the Claude Code mark itself, its licence (MIT, LobeHub) is explicit, and the file is used unmodified (rasterised, cropped, scaled). A file licence does not license the trademark: the Claude Code name and mark belong to Anthropic, PomoQuote is not affiliated with or endorsed by Anthropic, and the icon only identifies the Claude Code data being shown (nominative use). **If Anthropic objects, or the owner prefers to ask Anthropic for written approval (marketing@anthropic.com) and use its own press-kit mark instead, delete the two `claude-on-*` files**: the widget then falls back to the neutral glyph (`claude-neutral-on-*`) with the name.
- **Antigravity:** the official Antigravity icon was chosen, not a Google or Gemini mark, because the widget shows Google Antigravity's usage and the press kit offers exactly this icon in a white and a full-colour version. Antigravity is not read by PomoQuote yet; the icon is packaged for when that provider is added.

Every file in `Assets/Providers/` must have a row above (a test checks this); `Assets/Providers/source/` keeps the unmodified source SVG of the Claude Code mark.
