## Provider logos (`Assets/Providers/`)

PomoQuote shows the logo of the AI service whose quota it displays, next to the numbers, so the user can tell the providers apart (nominative use). **The names and marks of OpenAI, Anthropic and Google belong to their owners. PomoQuote is not affiliated with, endorsed by or sponsored by any of them.** A file licence (CC0, MIT) is not a trademark licence, so each vendor's own terms were checked; the result per provider is below. Nothing is fetched at run time: the files are packaged in the program. The logos are only cropped of their empty margin (in memory, at load time) and scaled; they are never recoloured or combined with other marks; an error, stale data or a near-full quota is shown by a separate badge and by text, never by changing the logo.

### Normalisation

At load time each logo is cut to its visible pixels (the official files keep wide transparent margins, which made the mark small), then scaled once per size with high quality so the mark fills an about 20 px box at full brightness (white versions on the dark widget, black or full-colour versions in dialogs). This is done in memory: the Codex, Antigravity and Claude files in `Assets/Providers/` are byte-identical to the vendors' files (tests check the Codex and Claude ones); the Claude PNG is Anthropic's press-kit file, also byte-identical (a test checks its SHA-256); only the neutral glyph is drawn for this project. No logo is ever recoloured to show an error.

### Decisions

- **Codex:** OpenAI publishes no separate Codex logo. The OpenAI Blossom identifies the OpenAI service (Codex) whose data is shown and is used unmodified, in the white and black versions OpenAI supplies, with the name "Codex" in the header, tooltip and accessible name. If OpenAI withdraws permission or the owner of this project prefers not to rely on it, delete `codex-on-dark.png` and `codex-on-light.png`: the widget then shows a neutral letter tile and the name.
- **Claude:** on 2026-11-24 the owner decided to use Anthropic's official mark from its public press kit replacing the neutral glyph and the community drawing that were shown before, and **accepts the trademark risk: no permission was obtained from Anthropic**. The press kit has no usage terms; the trademark guidelines (quoted word for word in the row above) allow the marks only "as specifically permitted by us and only in materials we approve beforehand", so this use is **not approved by Anthropic**. The mark is used unmodified (only cropped of empty margin and uniformly scaled, never recoloured, also not by error badges), only to identify the Claude data shown, and PomoQuote is not affiliated with or endorsed by Anthropic. **To ask for approval:** marketing@anthropic.com is the only contact the guidelines page publishes, and it is published as "If you have an existing business relationship with Anthropic and want to use our trademarks in a press release, on your website, or in another context, please email marketing@anthropic.com." It is therefore a contact, not a promise of approval, and PomoQuote has no such relationship. **To revert to the neutral glyph:** delete `Assets/Providers/claude-on-dark.png` and `Assets/Providers/claude-on-light.png`; there is no code change: the widget falls back to `claude-neutral-on-*` and the name. Why the Spark and not another kit file: it is the symbol (the smallest mark that identifies Claude, square, readable at 18 to 20 px); the wordmark logos and the Claude Code logo (the spark with the wordmark) are too wide for a 20 px box, and the app-icon versions are boxed squares; its Clay colour is bright on the dark widget, so the kit's Ivory or Slate variants are not needed.
- **Antigravity:** the official Antigravity icon was chosen, not a Google or Gemini mark, because the widget shows Google Antigravity's usage and the press kit offers exactly this icon in a white and a full-colour version. Antigravity is not read by PomoQuote yet; the icon is packaged for when that provider is added.

Every file in `Assets/Providers/` must have a row above (a test checks this).
