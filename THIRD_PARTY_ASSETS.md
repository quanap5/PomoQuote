PomoQuote itself is MIT licensed (see [LICENSE](LICENSE)). The assets with their own terms are listed here. Other bundled assets (sentences, mascot, sounds, wallpapers, weather icons, PomoQuote logo) are listed in the `CREDITS.md` file of their folder.

## Provider logos (`Assets/Providers/`)

PomoQuote shows the logo of the AI service whose quota it displays, next to the numbers, so the user can tell the providers apart (nominative use). **The names and marks of OpenAI, Anthropic and Google belong to their owners. PomoQuote is not affiliated with, endorsed by or sponsored by any of them.** A file licence (CC0, MIT) is not a trademark licence, so each vendor's own terms were checked; the result per provider is below. Nothing is fetched at run time: the files are packaged in the program. The logos are only cropped of their empty margin (in memory, at load time) and scaled; they are never recoloured or combined with other marks; an error, stale data or a near-full quota is shown by a separate badge and by text, never by changing the logo.

### Normalisation

At load time each logo is cut to its visible pixels (the official files keep wide transparent margins, which made the mark small), then scaled once per size with high quality so the mark fills an about 20 px box at full brightness (white versions on the dark widget, black or full-colour versions in dialogs). This is done in memory: the Codex and Antigravity files in `Assets/Providers/` are byte-identical to the vendors' files (a test checks the Codex one); the Claude PNG is a rasterisation of the lobe-icons SVG (see its row) and the neutral glyph is drawn for this project. No logo is ever recoloured to show an error.

### Decisions

- **Codex:** OpenAI publishes no separate Codex logo. The OpenAI Blossom identifies the OpenAI service (Codex) whose data is shown and is used unmodified, in the white and black versions OpenAI supplies, with the name "Codex" in the header, tooltip and accessible name. If OpenAI withdraws permission or the owner of this project prefers not to rely on it, delete `codex-on-dark.png` and `codex-on-light.png`: the widget then shows a neutral letter tile and the name.
- **Claude Code:** the owner asked for the Claude icon. Candidates checked on 2026-11-24: (1) Anthropic's own press kit (anthropic.com/news "Download press kit", `https://assets.claude.com/ae59ca4ca194dac9c9dc3bc78c5829468cb0e8af.zip`: Claude Spark, Claude icon, Claude logo and the Claude Code logo, which is the orange spark with the wordmark; no usage terms in the kit); (2) **lobe-icons** (MIT) `claudecode-color.svg` (a drawing of the Claude Code terminal mascot) and `claude-color.svg`; (3) **Simple Icons** (CC0 files) `claude.svg` (the Claude spark, commit `7a6199a2ac7d20b529f863b6aceb20d2c6529207` of 2024-11-29). Anthropic's [trademark guidelines](https://www.anthropic.com/legal/trademark-guidelines) say its marks may be used "only as specifically permitted by us and only in materials we approve beforehand" and forbid alterations, so the press kit was not used without approval. The icon currently shipped is the **lobe-icons drawing of the Claude Code mascot**: **a community drawing by LobeHub (MIT), not an official Anthropic asset, and not approved by Anthropic**; the MIT licence is explicit for the file but is not a trademark licence. PomoQuote is not affiliated with or endorsed by Anthropic, and the icon only identifies the Claude Code data being shown. **The owner decides whether to keep it, ask Anthropic (marketing@anthropic.com) and use the press-kit mark instead, or go back to the neutral glyph. To go back: delete `Assets/Providers/claude-on-dark.png` and `Assets/Providers/claude-on-light.png` (and `Assets/Providers/source/`); there is no code change: the widget falls back to `claude-neutral-on-*` and the name.**
- **Antigravity:** the official Antigravity icon was chosen, not a Google or Gemini mark, because the widget shows Google Antigravity's usage and the press kit offers exactly this icon in a white and a full-colour version. Antigravity is not read by PomoQuote yet; the icon is packaged for when that provider is added.

Every file in `Assets/Providers/` must have a row above (a test checks this); `Assets/Providers/source/` keeps the source SVG of the lobe-icons Claude Code icon.
